# Gradient Descent



This project implements the Adaptive Linear Neuron (Adaline) algorithm from scratch using Python and NumPy. Adaline is an early type of artificial neuron that uses gradient descent to minimize a cost function and serves as a fundamental building block for understanding more complex neural networks.

# Key Features



Custom implementation of Adaline with batch and stochastic gradient descent

Support for data shuffling and random initialization

Manual feature standardization for better convergence

Visualization of decision boundaries and learning progress

Applied to the Iris dataset (Setosa vs. Versicolor classification task)

# What I Learned

How to implement weight initialization, net input, activation functions, and predict methods from scratch

Practical application of NumPy matrix operations for ML

Differences between perceptron and Adaline training (update rule, error minimization)
